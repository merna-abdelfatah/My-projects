# E-Commerce Database

A SQL Server database project for an E-Commerce system.

## Project Overview

This project is designed to manage the main operations of an E-Commerce system, including:

- Customers
- Products
- Categories
- Suppliers
- Orders
- Payments
- Shipments
- Coupons

## Database Features

- Primary Keys and Foreign Keys
- Constraints and Relationships
- SQL Functions
- Stored Procedures
- Triggers
- Indexes
- Transactions and Error Handling
- Order Status Auditing

## Technologies

- SQL Server
- T-SQL
- SQL Server Management Studio (SSMS)
